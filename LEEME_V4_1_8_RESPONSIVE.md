# RutaRentable PRO Web 4.1.8 — Responsive Desktop

Cambios visuales:
- Adaptación para laptops, monitores Full HD y pantallas ultrawide.
- Menú lateral con scroll vertical independiente cuando no cabe en la altura disponible.
- Tablas con desplazamiento horizontal interno sin romper la página.
- Filtros y barras de herramientas se ajustan y envuelven en resoluciones pequeñas.
- Grillas de tarjetas se compactan en laptops angostas.
- El contenido se limita en monitores muy anchos para mantener legibilidad.

No se modifica:
- Firebase / Firestore
- Google Sign-In
- Datos y cálculos
- Selector de semanas
- Restaurantes
- Administración de usuarios
