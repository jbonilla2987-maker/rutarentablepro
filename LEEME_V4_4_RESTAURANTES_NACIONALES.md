# RutaRentable PRO Web 4.4.0 — Restaurantes nacionales

Cambios del módulo Restaurantes:
- Selector por provincia de Panamá.
- Muestra hasta 10 restaurantes ordenados por distancia desde la ubicación del navegador.
- El ranking ya no usa puntuación como criterio principal.
- Conserva puntuación y reseñas solo como información adicional.
- Botones Ver en mapa y Cómo llegar.
- Requiere Google Maps JavaScript API + Places API y permiso de ubicación.

No se modificó la lógica de jornadas, Firebase, usuarios, cálculos ni sincronización.
