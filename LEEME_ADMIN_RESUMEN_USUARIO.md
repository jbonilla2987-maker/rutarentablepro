# Visor administrador — Resumen de usuario

El botón **Ver resumen** abre una subpantalla exclusiva para administrador con indicadores compactos: ganancia neta, InDrive, Uber, viajes privados, gasolina, kilómetros, horas y ganancia por kilómetro.

El JSON crudo ya no se muestra en pantalla. El administrador conserva el botón **Descargar JSON** para respaldo. La pantalla es de solo lectura.
